# Binaries Directory (`bin/`)

Place `llama.cpp` Windows binaries here.

### Required Binary
- `llama-server.exe` (and corresponding runtime DLLs such as `llama.dll`, `ggml.dll`, `libomp.dll`, etc.)

Download official release binaries:
- [llama.cpp Releases on GitHub](https://github.com/ggerganov/llama.cpp/releases)
- Recommended: `llama-b*-bin-win-cpu-x64.zip` (or AVX2 / CUDA build depending on hardware).
